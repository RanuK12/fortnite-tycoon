# UEFN Setup Instructions

## Prerequisites
- Windows 10/11 (64-bit)
- Epic Games Launcher installed
- UEFN (Unreal Editor for Fortnite) installed via Epic Games Launcher
- Git (for version control)

## Setup Steps
1. Clone this repository to your Windows machine.
2. Open Epic Games Launcher → Library → Unreal Engine → UEFN → Install (if not already).
3. Launch UEFN from the Epic Games Launcher.
4. In UEFN, select "Open Project" and navigate to the cloned repository folder.
5. UEFN will detect the Verse project and load the map.
6. To compile Verse scripts, press `Ctrl + Shift + B` or use the Build button in the toolbar.
7. To test the map, click the "Launch Session" button in UEFN.
8. For publishing, follow Epic's publishing guidelines from within UEFN.

## Notes
- Verse compilation errors will appear in the Output log.
- Ensure you have the latest version of UEFN for compatibility with Verse 2.0.
- Refer to the official UEFN documentation for advanced features: https://docs.unrealengine.com/uefn/
