# Fortnite Tycoon Map

Mapa tycoon para Fortnite (UEFN/Verse) diseñado para retener jugadores 45+ minutos por sesión.

## ¿Qué es?
Este proyecto contiene el código Verse y la estructura para un mapa tycoon en Fortnite utilizando el Unreal Editor for Fortnite (UEFN). El objetivo es crear una experiencia atractiva que retenga a los jugadores durante sesiones largas.

## Stack
- **Verse**: Lenguaje de programación de UEFN para la lógica del juego.
- **UEFN**: Unreal Editor for Fortnite, requerido para compilar y publicar el mapa.

## Requisitos
- **Windows**: UEFN solo está disponible en Windows. En esta Mac solo se puede editar el código Verse, pero para compilar y probar se necesita una PC con Windows y UEFN instalado.
- **UEFN**: Descargable desde la Epic Games Store (requiere cuenta de Epic Games).

## Estructura de carpetas
- `/verse`: Código Verse del mapa.
- `/docs`: Documentación y especificaciones.
- `/design`: Diseños, bocetos y assets conceptuales.

## Cómo compilar
1. Abrir el proyecto en UEFN en una PC con Windows.
2. Copiar la carpeta `/verse` al proyecto de UEFN (o integrar el código Verse en el proyecto).
3. En UEFN, probar el mapa dentro del editor.
4. Cuando esté listo, publicar el mapa en Fortnite a través de UEFN.
