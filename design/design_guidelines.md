# Guías de Diseño para Fortnite Tycoon

## Objetivo

Este documento recopila las directrices de diseño para el mapa **Fortnite Tycoon**, asegurando que sea modular, atractivo y retente a los jugadores por más de 45 minutos.

## Estructura Modular

- **Módulos de diseño**: Cada módulo debe ser independiente para facilitar actualizaciones y personalizaciones.

## Requisitos Clave

- **Compatibilidad**: Diseñado para UEFN y compilable en Windows.
- **Experiencia de juego**: Incluir elementos interactivos y mecánicas que fomenten la exploración y retención.
